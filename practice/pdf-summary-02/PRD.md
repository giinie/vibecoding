# PRD: PDF 문서 요약 웹 애플리케이션

## 1. 개요

### 1.1 프로젝트 정보
- **프로젝트명**: PDF 문서 요약 AI
- **버전**: 1.0.0
- **작성일**: 2026-01-14
- **프로젝트 경로**: `/Users/giinie/JWS/PyCharm/vibecoding/practice/pdf-summary-02`

### 1.2 프로젝트 목적
사용자가 PDF 문서를 업로드하면 AI가 자동으로 텍스트를 추출하고, 핵심 내용을 한국어로 요약하여 제공하는 웹 애플리케이션입니다.

### 1.3 대상 사용자
- 긴 PDF 문서를 빠르게 파악해야 하는 직장인
- 논문이나 리포트를 요약해야 하는 학생
- 다량의 문서를 처리해야 하는 연구원
- 빠른 문서 검토가 필요한 일반 사용자

## 3. 기능 요구사항

### 3.1 핵심 기능

#### F1: PDF 파일 업로드
| 항목 | 상세 |
|------|------|
| **우선순위** | P0 (필수) |
| **설명** | 사용자가 PDF 파일을 선택하여 업로드할 수 있다 |
| **입력 방식** | 1) 파일 선택 버튼 클릭 2) 드래그 앤 드롭 |
| **허용 형식** | PDF (.pdf) 파일만 허용 |
| **최대 크기** | 50MB |
| **검증 항목** | 파일 형식, 파일 크기, 파일 유효성 |

**상세 요구사항**:
- [ ] 파일 선택 버튼 클릭 시 파일 탐색기 열림
- [ ] 드래그 앤 드롭 영역에 시각적 피드백 제공
- [ ] 잘못된 파일 형식 업로드 시 에러 메시지 표시
- [ ] 파일 크기 초과 시 에러 메시지 표시

## 6. API 명세

### 6.1 서버리스 함수 엔드포인트

#### POST /api/summarize

**요청**:
```javascript
{
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: {
    text: string,      // 추출된 PDF 텍스트
    maxLength?: number // 최대 요약 길이 (선택)
  }
}
```

**응답 (성공)**:
```javascript
{
  success: true,
  summary: string,         // 요약된 텍스트
  originalLength: number,  // 원문 글자 수
  summaryLength: number,   // 요약 글자 수
  ratio: number           // 압축 비율 (%)
}
```

**응답 (실패)**:
```javascript
{
  success: false,
  error: {
    code: string,    // 에러 코드
    message: string  // 에러 메시지
  }
}
```

### 6.2 OpenRouter API 호출 구조

```javascript
{
  endpoint: 'https://openrouter.ai/api/v1/chat/completions',
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ${OPENROUTER_API_KEY}',
    'Content-Type': 'application/json',
    'HTTP-Referer': '${SITE_URL}',
    'X-Title': 'PDF Summary App'
  },
  body: {
    model: 'deepseek/deepseek-chat',
    messages: [
      {
        role: 'system',
        content: '당신은 문서 요약 전문가입니다. 주어진 텍스트를 한국어로 명확하고 간결하게 요약해주세요. 핵심 내용과 주요 포인트를 빠뜨리지 않되, 원문의 10-20% 분량으로 요약하세요.'
      },
      {
        role: 'user',
        content: '다음 문서를 요약해주세요:\n\n${extractedText}'
      }
    ],
    temperature: 0.3,
    max_tokens: 2000
  }
}
```

## 11. 제약 사항 및 가정

### 11.1 제약 사항

1. **텍스트 PDF만 지원**: 이미지 기반 PDF는 OCR이 필요하므로 지원하지 않음
2. **파일 크기 제한**: 50MB (브라우저 메모리 및 처리 시간 고려)
3. **요약 길이 제한**: OpenRouter API의 토큰 제한 (max_tokens: 2000)
4. **동시 처리**: 한 번에 하나의 파일만 처리 가능
5. **오프라인 미지원**: API 호출을 위해 인터넷 연결 필요

### 11.2 가정

1. 사용자는 현대적인 웹 브라우저를 사용한다
2. 업로드되는 PDF는 텍스트 추출이 가능한 형식이다
3. OpenRouter API는 안정적으로 작동한다
4. Vercel 무료 티어의 제한 내에서 운영한다
