- **작성일**: 2026-01-14
- **작성자**: Product Planning Manager
- **프로젝트 유형**: 웹 기반 AI 문서 요약 서비스

## 1. Executive Summary

PDF 문서 요약 웹 애플리케이션은 사용자가 업로드한 PDF 파일의 텍스트를 자동으로 추출하고, AI를 활용하여 한글로 핵심 내용을 요약해주는 서비스입니다. 브라우저만 있으면 누구나 무료로 사용할 수 있으며, 별도의 설치나 회원가입 없이 즉시 이용 가능합니다.

### 주요 가치 제안
- **시간 절약**: 긴 PDF 문서를 읽는 시간을 대폭 단축
- **핵심 파악**: AI가 중요한 내용만 추출하여 제공
- **접근성**: 웹 브라우저만 있으면 언제 어디서나 사용 가능
- **무료 서비스**: OpenRouter의 무료 DeepSeek 모델 활용

---

## 2. Problem Statement

### 해결하고자 하는 문제
현대인들은 매일 방대한 양의 문서를 접하지만, 모든 문서를 자세히 읽을 시간이 부족합니다. 특히 PDF 형식의 보고서, 논문, 계약서 등은 분량이 많아 핵심 내용 파악에 많은 시간이 소요됩니다.

### 타겟 사용자의 페인 포인트
1. **시간 부족**: 모든 문서를 꼼꼼히 읽을 시간이 없음
2. **정보 과부하**: 중요한 내용과 부차적인 내용의 구분 어려움
3. **접근성 제약**: 유료 도구나 복잡한 설치 과정이 장벽으로 작용
4. **언어 장벽**: 영문 요약 도구가 많아 한국어 사용자에게 불편

### 시장 기회
- 한국어 문서 요약 도구 수요 증가
- 무료 AI API (DeepSeek) 활용 가능
- 웹 기반 서비스로 접근성 극대화

## 5. Feature Specifications

### 5.1 필수 기능 (Must-Have)

#### F-001: PDF 파일 업로드
- **우선순위**: P0 (Critical)
- **설명**: 사용자가 PDF 파일을 선택하여 업로드할 수 있는 기능
- **기술 요구사항**:
  - 드래그 앤 드롭 지원 (HTML5 Drag & Drop API)
  - 파일 선택 버튼 제공 (input type="file")
  - 파일 형식 검증 (MIME type: application/pdf)
  - 파일 크기 제한: 최대 50MB
- **입력**: PDF 파일 (단일 파일)
- **출력**: 파일 정보 (이름, 크기), 업로드 상태
- **에러 처리**:
  - 비-PDF 파일 업로드 시: "PDF 파일만 업로드 가능합니다" 경고
  - 50MB 초과 시: "파일 크기는 50MB 이하여야 합니다" 경고

#### F-002: PDF 텍스트 추출
- **우선순위**: P0 (Critical)
- **설명**: 업로드된 PDF에서 텍스트를 자동으로 추출
- **기술 요구사항**:
  - pdf.js 라이브러리 사용 (CDN: Mozilla PDF.js)
  - 클라이언트 사이드 처리 (서버 전송 없음)
  - 모든 페이지 텍스트 추출
  - 진행률 표시 (페이지별)
- **입력**: PDF 파일 (ArrayBuffer)
- **출력**: 추출된 전체 텍스트 (String)
- **성능 목표**:
  - 10MB PDF: 10초 이내 추출 완료
  - 진행률 업데이트 주기: 1초마다
- **에러 처리**:
  - 손상된 PDF: "PDF 파일을 읽을 수 없습니다" 경고
  - 텍스트 없는 PDF: "추출할 텍스트가 없습니다" 경고

#### F-003: AI 요약 생성
- **우선순위**: P0 (Critical)
- **설명**: 추출된 텍스트를 AI API로 전송하여 한글 요약 생성
- **기술 요구사항**:
  - OpenRouter API 사용
  - 모델: deepseek/deepseek-chat (무료)
  - 환경변수: OPENROUTER_API_KEY
  - Temperature: 0.7
  - Max tokens: 2000
- **입력**: 추출된 텍스트 (최대 4000자)
- **출력**: 한글 요약문 (500-1000자)
- **프롬프트 구조**:
  ```
  System: 당신은 한국어 문서 요약 전문가입니다. 핵심 내용을 간결하게 정리해주세요.
  User: [추출된 텍스트]
  ```
- **요약 형식**:
  - 제목 (한 줄)
  - 핵심 요약 (3-5 문단)
  - 주요 키워드 (3-5개)
- **성능 목표**:
  - 평균 응답 시간: 15초 이내
- **에러 처리**:
  - API 키 오류: "API 키를 확인해주세요" 경고
  - API 응답 실패: "요약 생성에 실패했습니다. 다시 시도해주세요" 경고
  - 타임아웃 (60초): "요청 시간이 초과되었습니다" 경고

#### F-004: 요약 결과 표시
- **우선순위**: P0 (Critical)
- **설명**: 생성된 요약문을 사용자에게 표시
- **기술 요구사항**:
  - Markdown 형식 지원 (굵기, 목록 등)
  - 가독성 좋은 타이포그래피
  - 모바일 반응형 레이아웃
- **입력**: AI 생성 요약문
- **출력**: 포맷팅된 요약 표시 영역
- **UI 요구사항**:
  - 제목: 20px, 굵게
  - 본문: 16px, 줄간격 1.6
  - 키워드: 뱃지 형태 (#태그)

#### F-005: 요약문 복사
- **우선순위**: P1 (High)
- **설명**: 요약 결과를 클립보드에 복사
- **기술 요구사항**:
  - Clipboard API 사용
  - 복사 성공 피드백 (토스트 메시지)
- **입력**: 요약문 텍스트
- **출력**: 클립보드에 복사 완료
- **에러 처리**:
  - 브라우저 미지원: "복사 기능을 지원하지 않는 브라우저입니다" 경고

### 5.2 권장 기능 (Should-Have)

#### F-006: 진행 상태 표시
- **우선순위**: P1 (High)
- **설명**: 처리 단계별 진행 상황을 시각적으로 표시
- **표시 단계**:
  1. 파일 업로드 중 (0-10%)
  2. 텍스트 추출 중 (10-50%)
  3. AI 요약 생성 중 (50-90%)
  4. 완료 (100%)
- **UI 요구사항**:
  - 프로그레스 바 (애니메이션)
  - 현재 단계 텍스트 표시
  - 예상 소요 시간 표시

#### F-007: 다국어 인터페이스 준비
- **우선순위**: P2 (Medium)
- **설명**: 향후 영어 등 다국어 지원을 위한 구조 설계
- **현재 버전**: 한국어만 지원
- **준비 사항**:
  - 텍스트를 변수로 분리
  - 언어 전환 구조 설계

### 5.3 선택 기능 (Could-Have)

#### F-008: 요약 길이 조절
- **우선순위**: P3 (Low)
- **설명**: 사용자가 요약문 길이를 선택할 수 있는 옵션
- **옵션**: 짧게 (300자), 보통 (500자), 길게 (1000자)

#### F-009: 이전 요약 기록
- **우선순위**: P3 (Low)
- **설명**: 브라우저 로컬 스토리지에 최근 요약 저장
- **제약**: 최대 5개 항목, 7일간 보관

### 5.4 제외 기능 (Won't-Have - V1)

- 클라우드 저장소 연동
- OCR (이미지 PDF 처리)
- 다중 파일 동시 처리
- 요약문 편집 기능

## 6. User Stories & Acceptance Criteria

### US-001: PDF 파일 업로드
**As a** 대학생 지수
**I want** PDF 파일을 쉽게 업로드할 수 있기를
**So that** 논문을 빠르게 요약할 수 있다

**Acceptance Criteria**:
- [ ] 드래그 앤 드롭으로 파일 업로드 가능
- [ ] "파일 선택" 버튼 클릭으로도 업로드 가능
- [ ] PDF가 아닌 파일은 업로드 거부
- [ ] 50MB 초과 파일은 업로드 거부
- [ ] 업로드된 파일명과 크기가 화면에 표시됨

### US-002: 텍스트 자동 추출
**As a** 직장인 민호
**I want** PDF에서 텍스트가 자동으로 추출되기를
**So that** 별도 작업 없이 바로 요약을 받을 수 있다

**Acceptance Criteria**:
- [ ] 업로드 후 자동으로 텍스트 추출 시작
- [ ] 추출 진행률이 실시간으로 표시됨
- [ ] 모든 페이지의 텍스트가 추출됨
- [ ] 10MB PDF 기준 10초 이내 추출 완료
- [ ] 추출 실패 시 명확한 오류 메시지 표시

### US-003: 한글 요약 받기
**As a** 연구원 수진
**I want** 추출된 텍스트가 한글로 요약되기를
**So that** 문서의 핵심 내용을 빠르게 파악할 수 있다

**Acceptance Criteria**:
- [ ] 텍스트 추출 완료 후 자동으로 요약 시작
- [ ] 요약문은 한글로 작성됨
- [ ] 요약문에 제목, 핵심 내용, 키워드 포함
- [ ] 평균 15초 이내에 요약 완료
- [ ] 요약 실패 시 재시도 옵션 제공

### US-004: 요약문 복사
**As a** 대학생 지수
**I want** 생성된 요약문을 쉽게 복사할 수 있기를
**So that** 다른 문서에 붙여넣어 활용할 수 있다

**Acceptance Criteria**:
- [ ] "복사" 버튼 클릭 한 번으로 전체 요약문 복사
- [ ] 복사 성공 시 "복사되었습니다" 메시지 표시
- [ ] 복사된 텍스트 형식이 가독성 있게 유지됨

### US-005: 모바일에서 사용
**As a** 직장인 민호
**I want** 모바일에서도 편하게 사용할 수 있기를
**So that** 이동 중에도 문서를 요약할 수 있다

**Acceptance Criteria**:
- [ ] 모바일 화면 크기에 맞게 레이아웃 조정
- [ ] 터치 인터랙션 정상 작동
- [ ] 텍스트가 화면 크기에 맞게 자동 줄바꿈
- [ ] 버튼과 입력 요소가 터치하기 적절한 크기

## 7. Technical Considerations

### 7.1 아키텍처 개요

```
┌─────────────────┐
│   Frontend      │
│  (index.html)   │
│                 │
│  - HTML5        │
│  - CSS3         │
│  - JavaScript   │
└────────┬────────┘
         │
         ├─────────┐
         │         │
    ┌────▼────┐  ┌▼──────────┐
    │ pdf.js  │  │ Vercel    │
    │ (CDN)   │  │ Function  │
    │         │  │ /api/     │
    └─────────┘  └┬──────────┘
                  │
             ┌────▼────────┐
             │ OpenRouter  │
             │ API         │
             │             │
             │ DeepSeek    │
             └─────────────┘
```

### 7.2 데이터 흐름

1. **파일 업로드 단계**
   - Input: PDF 파일 (File object)
   - Process: 파일 검증 (형식, 크기)
   - Output: ArrayBuffer

2. **텍스트 추출 단계**
   - Input: PDF ArrayBuffer
   - Process: pdf.js 파싱 (클라이언트 사이드)
   - Output: 텍스트 문자열

3. **요약 생성 단계**
   - Input: 텍스트 (최대 4000자)
   - Process: Vercel Function → OpenRouter API 호출
   - Output: 한글 요약문 (JSON)

4. **결과 표시 단계**
   - Input: 요약문 JSON
   - Process: HTML 렌더링
   - Output: 화면 표시

### 7.3 기술 스택 세부 사항

#### Frontend
- **HTML5**: 시맨틱 마크업, Drag & Drop API
- **CSS3**: Flexbox/Grid 레이아웃, CSS Variables, 반응형 디자인
- **JavaScript**: ES6+ (Arrow functions, Promises, Async/await)
- **pdf.js**: v3.11+ (Mozilla CDN)

#### Backend (Vercel Serverless)
- **Runtime**: Node.js 18.x
- **Framework**: Vercel Functions (Express 기반)
- **API**: OpenRouter REST API
- **Environment**: OPENROUTER_API_KEY 환경변수

#### Deployment
- **Platform**: Vercel
- **Domain**: 자동 생성 (.vercel.app) 또는 커스텀 도메인
- **SSL**: 자동 제공 (Let's Encrypt)
- **CDN**: 글로벌 엣지 네트워크

### 7.4 보안 고려사항

   - Vercel Function에서 적절한 CORS 헤더 설정

## 11. Risks & Mitigations

### Risk Matrix

| 위험 요소 | 발생 가능성 | 영향도 | 심각도 | 대응 전략 |
|-----------|-------------|--------|--------|-----------|
| OpenRouter API 장애 | 중 | 높음 | 🔴 High | Fallback 모델, 재시도 로직 |
| pdf.js 호환성 문제 | 낮음 | 중간 | 🟡 Medium | 버전 고정, 대체 라이브러리 준비 |
| 대용량 PDF 처리 실패 | 높음 | 중간 | 🟡 Medium | 파일 크기 제한, 사용자 안내 |
| 브라우저 호환성 이슈 | 중 | 낮음 | 🟢 Low | Polyfill, 지원 브라우저 명시 |
| API 비용 초과 | 낮음 | 중간 | 🟡 Medium | 무료 티어 모니터링, 사용량 제한 |

### 세부 위험 분석 및 대응

#### R-001: OpenRouter API 장애
- **위험 설명**: API 서버 다운, 네트워크 오류, 요청 제한 초과
- **발생 가능성**: 중간 (월 1-2회)
- **영향도**: 높음 (서비스 중단)
- **대응 전략**:
  - 재시도 로직 구현 (최대 3회, 지수 백오프)
  - 타임아웃 설정 (60초)
  - 사용자에게 명확한 오류 메시지 제공
  - 대체 API 엔드포인트 준비 (다른 모델)

#### R-002: 대용량 PDF 처리 실패
- **위험 설명**: 메모리 부족, 브라우저 크래시, 처리 시간 초과
- **발생 가능성**: 높음 (큰 파일 업로드 시)
- **영향도**: 중간 (특정 파일만 영향)
- **대응 전략**:
  - 파일 크기 50MB로 엄격히 제한
  - 경고 메시지: "큰 파일은 처리 시간이 길어질 수 있습니다"
  - 청크 단위 처리 고려 (향후)
  - 서버 사이드 처리 옵션 준비 (Phase 2)

#### R-003: 텍스트 없는 PDF (이미지 기반)
- **위험 설명**: 스캔 PDF, 이미지로만 구성된 문서
- **발생 가능성**: 중간 (사용자 유형에 따라 다름)
- **영향도**: 중간 (특정 사용자 경험 저하)
- **대응 전략**:
  - 텍스트 추출 전 검증 로직
  - 명확한 안내: "이 PDF는 텍스트 추출이 불가능합니다"
  - OCR 기능 안내 (향후 지원 예정)

#### R-004: API 비용 초과
- **위험 설명**: 무료 티어 한도 초과로 서비스 중단
- **발생 가능성**: 낮음 (초기 사용자 적음)
- **영향도**: 중간 (일시적 서비스 제한)
- **대응 전략**:
  - API 사용량 모니터링 대시보드
  - 일일/월간 한도 설정
  - 한도 근접 시 알림
  - 유료 플랜 전환 준비

#### R-005: 보안 취약점
- **위험 설명**: API 키 노출, XSS 공격, CSRF 공격
- **발생 가능성**: 낮음 (정적 사이트)
- **영향도**: 높음 (서비스 신뢰도 하락)
- **대응 전략**:
  - API 키는 환경변수로만 관리
  - 입력 검증 및 이스케이프
  - CSP 헤더 설정
  - 정기적인 보안 점검

## 15. Appendix

### A. 용어 정의

- **PDF**: Portable Document Format, 이식 가능한 문서 형식
- **AI 요약**: 인공지능을 활용한 자동 문서 요약
- **OpenRouter**: 다양한 AI 모델을 통합 제공하는 API 플랫폼
- **DeepSeek**: 중국의 AI 연구 기업이 개발한 대규모 언어 모델
- **pdf.js**: Mozilla에서 개발한 JavaScript PDF 렌더링 라이브러리
- **Vercel**: 프론트엔드 및 서버리스 함수 배포 플랫폼
- **Serverless Function**: 서버 관리 없이 코드를 실행하는 클라우드 함수
