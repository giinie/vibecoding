# Fridge Chef 수동 QA 체크리스트

## 목적

이 문서는 실제 사용자 관점에서 핵심 기능을 빠르게 점검하기 위한 수동 QA 체크리스트입니다.
기본 원칙은 다음과 같습니다.

- Python 명령은 항상 `uv` 사용
- 앱 실행은 `uv run streamlit run app.py`
- 공유 링크 확인 시 `APP_BASE_URL`이 현재 실행 URL과 맞는지 먼저 확인

---

## 1. 사전 준비

### 1.1 앱 실행

```bash
uv run streamlit run app.py
```

기본 접속 URL:

- `http://localhost:8501`

### 1.2 환경 확인

- `.env`에 `OPENROUTER_API_KEY`가 설정되어 있는가
- 공유 링크 점검이 필요하면 `APP_BASE_URL`이 현재 접속 URL과 일치하는가
- 테스트 데이터를 보존해야 한다면 실제 `fridge_chef.db`를 백업했는가

---

## 2. 핵심 사용자 여정 체크리스트

## 2.1 게스트 사용자 흐름

### A. 재료 인식 → 레시피 생성

- [ ] `1_🍳_재료_인식` 페이지에서 이미지 업로드가 된다
- [ ] 재료 인식 후 `recognized_ingredients`가 채워진다
- [ ] `2_📖_레시피_생성` 페이지에서 인식된 재료가 보인다
- [ ] 난이도/조리시간/식이제한 설정 후 레시피 생성이 된다
- [ ] 생성된 레시피 카드에 이름, 시간, 난이도, 재료, 순서가 정상 표시된다

### B. 게스트 임시 저장

- [ ] 비로그인 상태에서 레시피 `💾 저장하기` 클릭 시 성공 메시지가 뜬다
- [ ] 사이드바에 `임시 저장 n개`가 표시된다
- [ ] 사이드바 `💾 임시 저장 보기` 버튼이 보인다
- [ ] `4_💾_저장된_레시피` 페이지에서 임시 저장 레시피 목록이 실제로 보인다
- [ ] 임시 저장 레시피 삭제 버튼이 동작한다
- [ ] 비로그인 상태에서는 공유/평점/영구 저장 관련 기능이 과도하게 노출되지 않는다

---

## 2.2 회원가입 / 로그인 흐름

### A. 회원가입

- [ ] 4자 미만 아이디는 가입되지 않는다
- [ ] 공백/특수문자 포함 아이디는 가입되지 않는다
- [ ] 4자 미만 비밀번호는 가입되지 않는다
- [ ] 정상 아이디/비밀번호로 가입 가능하다

### B. 로그인

- [ ] 정상 계정으로 로그인된다
- [ ] 잘못된 비밀번호로 로그인 시 실패 메시지가 뜬다
- [ ] 로그인 후 `user_id`, `is_authenticated`, `username` 세션 상태가 반영된다

### C. 게스트 저장 이관

- [ ] 게스트 상태에서 임시 저장한 레시피가 있는 상태로 로그인한다
- [ ] 로그인 직후 “임시 저장 레시피 n개를 계정에 저장했습니다” 안내가 보인다
- [ ] `4_💾_저장된_레시피` 페이지에서 해당 레시피가 DB 저장 목록으로 보인다
- [ ] 로그인 후 세션의 guest `saved_recipes`는 비워진다

---

## 2.3 저장된 레시피 관리

- [ ] 로그인 상태에서 저장된 레시피 목록이 정상 로드된다
- [ ] 검색 필터가 레시피 이름 기준으로 동작한다
- [ ] 태그 필터가 동작한다
- [ ] 정렬(최근 저장순/오래된 순/높은 평점순)이 동작한다
- [ ] 메모/태그 수정이 저장된다
- [ ] 평점 변경이 반영된다
- [ ] 삭제가 정상 동작한다

---

## 2.4 공유 기능

### A. 공유 링크 생성

- [ ] 로그인 상태 저장 레시피에서 `📤 공유` 클릭 시 공유 UI가 열린다
- [ ] 공유 링크가 표시된다
- [ ] 공유 링크가 `APP_BASE_URL?share_id=...` 형식이다
- [ ] QR 코드가 생성된다
- [ ] 텍스트 공유 영역에 레시피 이름/시간/난이도/재료/순서가 들어간다

### B. 공유 링크 소비

- [ ] 새 브라우저 탭에서 공유 링크를 열 수 있다
- [ ] `app.py`에서 공유된 레시피 화면이 열린다
- [ ] 유효하지 않은 `share_id`는 오류 메시지를 보여준다
- [ ] 공유 화면에서는 편집/삭제 같은 소유자 전용 액션이 노출되지 않는다

### C. 권한 체크

- [ ] 다른 사용자 레시피 ID로 공유를 켜거나 끌 수 없다
- [ ] 소유자 본인 레시피는 정상적으로 공유 on/off 된다

---

## 2.5 대시보드 / 요리 기록

- [ ] 대시보드의 저장 개수 / 요리 횟수 / 평균 평점 / 연속 요리일이 정상 표시된다

## 4. 빠른 검증 명령

### 4.1 전체 테스트

```bash
uv run pytest tests/ -v
```

### 4.2 핵심 문법 검증

```bash
uv run python -m compileall app.py db services components pages tests utils
```

### 4.3 공유 링크/환경 검증 시 확인할 것

- `APP_BASE_URL`
- 현재 브라우저 접속 주소
- `share_id`가 포함된 URL 형식
